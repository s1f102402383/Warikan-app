# What's
5Daysインターンシップ用プログラムのサンプルです。

# アプリケーション概要
OCR APIを使った画像データ管理アプリケーションの作成。
ユーザは画像をアップロードして、その画像に記載されている文字をテキストデータとして受け取ることが出来きるアプリ。
また、一度アップロードした画像に対する結果テキストを検索が可能。

# 起動方法
1. プロジェクトルートにて以下のコマンドを実行してください。
   ```
   docker compose up -d
   ```
2. http://localhost:8800 へアクセスしてください。

# 技術スタック
- 言語: Python
  - 仮想環境: uv
  - フロントエンド: streamlit
- 実行環境: Docker
- DB: MariaDB
