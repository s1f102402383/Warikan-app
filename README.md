# Warikan-app（レシート読み取り割り勘アプリ）

旅行などで複数人がお金を立て替えたとき、レシートの画像をアップロードするだけで「誰が誰にいくら払えばよいか」を自動で計算するWebアプリです。

ソリマチ株式会社のインターンシップ（2026年9月）で、チームで開発しました。

## 開発のきっかけ

インターンの課題は「OCR APIを使った画像データ管理アプリ」でした。OCRはレシートを読み取れる点が特長だったので、それを活かせるテーマを考えました。

旅行に行ったとき、みんなでレシートを見ながら「誰が誰にいくら払うか」を計算するのが毎回面倒だったため、その計算を一瞬で終わらせるアプリにしました。

## 主な機能

- レシート画像のアップロードとOCRによる文字の読み取り
- 読み取った結果の保存・削除・検索
- 旅行の登録と、旅行ごとのメンバー登録
- 旅行ごとに、誰が誰にいくら払えばよいかを自動で計算

## 開発の流れと担当

| 日程 | 内容 |
|---|---|
| 1日目 | ペアプログラミングで開発の大枠を作成。データベースの接続・登録・削除、OCR APIとの連携、検索機能を実装 |
| 2日目 | 割り勘機能を企画・実装。旅行IDごとにメンバーを登録し、読み取った金額から精算額を計算するところまで作成 |
| 3日目 | 割り勘計算の完成を受けて、UIの使い勝手の改善や画面の自動遷移を実装 |

## 工夫した点

- 課題のOCR APIの特長（レシートを読み取れること）から、実際の困りごとに結びつくアプリを企画しました。
- 旅行IDでデータを区別し、同じメンバーでも旅行ごとに精算できるようにしました。
- 入力の手間を減らすため、処理後に画面が自動で切り替わるようにしました。

## 技術スタック

- 言語：Python
- フロントエンド：Streamlit
- DB：MariaDB
- 実行環境：Docker
- パッケージ管理：uv

## 起動方法

プロジェクトのルートで次を実行し、http://localhost:8800 にアクセスします。

```bash
docker compose up -d
```
